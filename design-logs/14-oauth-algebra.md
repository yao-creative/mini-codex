The OAuth Authorization Code + PKCE flow is interesting because it has **several algebraic layers**. Each layer answers a different modeling question.

---

# Layer 1 — Objects (Sets)

First define the sets.

$$
\begin{aligned}
U &:= \text{Users}\
C &:= \text{Clients}\
A &:= \text{Authorization Servers}\
R &:= \text{Resource Servers}\
Q &:= \text{Authorization Requests}\

These are merely carrier sets.

Nothing interesting has happened yet.

# Putting it all together

From the perspective of category theory and protocol design, the OAuth Authorization Code + PKCE flow decomposes cleanly into:

| Structure                     | OAuth interpretation                                           |
| ----------------------------- | -------------------------------------------------------------- |
| **Sets**                      | Users, Clients, Codes, Tokens, Verifiers, Challenges           |
| **Cartesian products**        | Authorization requests, token requests, token records          |
| **Morphisms**                 | `authorize`, `exchange`, `refresh`, `revoke`                   |
| **Predicates**                | PKCE check, redirect URI equality, expiration, scope inclusion |
| **Partial functions**         | Protocol operations that may reject invalid inputs             |
| **Labeled transition system** | The protocol execution over local states                       |
| **Product automaton**         | Client × Browser × Authorization Server × Resource Server      |
| **Free category**             | Legal protocol traces formed by composing protocol actions     |
| **Coalgebra**                 | The running authorization server as a reactive system          |
| **Term algebra**              | The protocol events interpreted by the state machine           |

This decomposition closely mirrors how protocol specifications (e.g., RFCs), formal verification (e.g., TLA+), and production implementations are typically structured: immutable message types (products), transition functions with guards (partial morphisms), and distributed state machines communicating by message passing.
